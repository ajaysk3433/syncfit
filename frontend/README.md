# SyncFit Pro Frontend

SyncFit Pro frontend application built with React and Vite.

## Available Scripts

In the frontend directory, you can run:

### `npm run dev` or `npm start`

Runs the app in development mode with Vite hot module replacement (HMR).\
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

### `npm test`

Launches the test runner in Vitest.\
Runs test suites and displays test results.

### `npm run build`

Builds the app for production to the `dist` folder.\
Optimizes and minifies the assets for maximum performance.

### `npm run preview`

Locally previews the production build.
